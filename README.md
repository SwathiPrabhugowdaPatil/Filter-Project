# Product Filter Web Application

An interactive, responsive product filter application built using vanilla HTML5, CSS3, and JavaScript. It allows users to dynamically search and filter items by keywords, categories, and price ranges in real time[cite: 3].

---

## 🚀 Features

* **Real-time Keyword Search:** Filter products instantly using an interactive search bar[cite: 3].
* **Category Filtering:** Select and toggle specific product categories dynamically[cite: 3].
* **Price Range Filter:** Slide to set a maximum price threshold with dynamic visual feedback[cite: 3].
* **Dynamic Grid Layout:** Displays products seamlessly inside a responsive content container[cite: 3].

---

## 🛠️ Tech Stack

* **HTML5:** Dynamic structure with semantically arranged layout[cite: 3]
* **CSS3:** Custom styles and layouts (`filter.css`)[cite: 3]
* **JavaScript:** DOM manipulation and filter logic (`filter.js`)[cite: 3]
* **Typography:** [Google Fonts (Open Sans)](https://fonts.google.com/specimen/Open+Sans)[cite: 3]
